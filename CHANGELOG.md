# Changelog

All notable changes to this project will be documented in this file.

## [0.0.5] (2026-10-31)

### Fixes

- Expand detection of variant types ([#15])
- Correctly render deeply nested anchor fragments ([#16])

## [0.0.4] (2026-10-30)

### Features

- Export `css` and the `CSS` type for reusable style fragments ([#10])

### Changes

- Require style modules to use the `.styles.ts` extension ([#13])
- Remove the `style` export ([#10])

### Fixes

- Improve Vite HMR when style modules or their dependencies change ([#11])

### Development

- Reorganize Vite plugin sources under `src/plugins/` ([#12])
- Expand README examples ([#9])

## [0.0.3] (2026-10-26)

### Changes

- Preserve identifier key casing in scoped names ([#7])

### Fixes

- Fully support HMR in the Vite plugin ([#5])
- Expand every `&` in nested selector keys ([#6])

## [0.0.2] (2026-10-25)

### Development

- Add badges to the readme ([#3])
- Expand logos ([#2])
- Add trusted publishing ([#1])

## [0.0.1] (2026-10-24)

### Features

- Initial release
